Python

Python이란?

Python은 문법이 간단하고 읽기 쉬워 프로그래밍을 처음 배우는 사람에게도 인기 있는 언어입니다.

주요 특징

  • 문법이 간단하고 읽기 쉽다.
  • 프로그래밍 입문자가 배우기 좋다.
  • 다양한 라이브러리를 사용할 수 있다.

사용 분야

인공지능 데이터 분석 웹 개발 자동화

코드 예제

print("Hello World")

실행 결과: Hello World

Python 퀴즈

다음 중 Python에서 화면에 문장을 출력하는 함수는 무엇일까요?

해설: Python에서 화면에 문장을 출력할 때는 print() 함수를 사용합니다. 예를 들어 print("Hello World")라고 작성하면 화면에 Hello World가 출력됩니다.

Java

Java란?

Java는 객체지향 프로그래밍을 기반으로 하는 대표적인 프로그래밍 언어입니다.

주요 특징

  • 객체지향 프로그래밍 언어이다.
  • 다양한 운영체제에서 사용할 수 있다.
  • 안정성과 확장성이 높다.

사용 분야

웹 개발 Android 서버 기업 시스템

코드 예제

System.out.println("Hello World");

실행 결과: Hello World

Java 퀴즈

Java의 대표적인 프로그래밍 방식은 무엇일까요?

해설: Java는 객체지향 프로그래밍을 중심으로 사용하는 언어입니다. 클래스와 객체 등의 개념을 이용하여 프로그램을 구조적으로 작성할 수 있습니다.

C Language

C 언어란?

C 언어는 컴퓨터 시스템과 소프트웨어 개발에 널리 사용되는 대표적인 프로그래밍 언어입니다.

주요 특징

  • 실행 속도가 빠르다.
  • 하드웨어와 가까운 프로그래밍이 가능하다.
  • 다른 프로그래밍 언어를 배우는 기초가 된다.

사용 분야

운영체제 임베디드 시스템 소프트웨어

코드 예제

#include <stdio.h>

int main() {
    printf("Hello World");
    return 0;
}

실행 결과: Hello World

C 언어 퀴즈

다음 중 C 언어에서 화면에 문장을 출력할 때 사용하는 함수는 무엇일까요?

해설: C 언어에서는 printf() 함수를 사용하여 화면에 문자열이나 값을 출력할 수 있습니다. 예를 들어 printf("Hello World");를 실행하면 Hello World가 출력됩니다.

HTML

HTML이란?

HTML은 웹 페이지의 구조와 내용을 만드는 마크업 언어입니다.

주요 특징

  • 웹 페이지의 구조를 만든다.
  • CSS와 함께 디자인을 구성한다.
  • JavaScript와 함께 웹 기능을 구현한다.

사용 분야

웹사이트 웹 앱 UI 웹 콘텐츠

코드 예제

<h1>Hello World</h1>

화면 결과: Hello World라는 제목이 표시됩니다.

HTML 퀴즈

다음 중 HTML에서 가장 큰 제목을 나타내는 태그는 무엇일까요?

해설: HTML의 h1 태그는 제목 태그 중 가장 높은 단계의 제목을 나타냅니다. h1부터 h6까지 있으며 숫자가 작을수록 제목의 단계가 높습니다.
