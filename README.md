# 💻 4대 개발 언어 가이드

Python, Java, C언어, HTML의 기본적인 특징과 사용 분야를 소개하는 웹사이트입니다.

각 언어의 간단한 설명과 주요 특징, 사용 분야, 코드 예제를 확인할 수 있으며, 마지막에는 퀴즈를 통해 학습한 내용을 확인할 수 있도록 제작했습니다.

---

## 📌 프로젝트 소개

프로그래밍을 처음 접하는 사람이 여러 개발 언어의 특징과 사용 분야를 쉽게 비교할 수 있도록 제작한 웹사이트입니다.

처음에는 단순히 개발 언어를 소개하는 것을 목표로 했지만, 제작 과정에서 사용자가 직접 참여할 수 있는 기능의 필요성을 느껴 **언어별 퀴즈 기능**을 추가했습니다.

---

## 🛠️ 사용 기술

| 기술         | 사용 목적                    |
| ---------- | ------------------------ |
| HTML       | 웹페이지의 구조 및 콘텐츠 작성        |
| CSS        | 색상, 크기, 배치 및 화면 디자인 구현   |
| JavaScript | 페이지 전환, 버튼 이벤트, 퀴즈 기능 구현 |

## ✨ 주요 기능

### 1. 개발 언어 소개

다음 네 가지 언어를 소개합니다.

* 🐍 Python
* ☕ Java
* 🔧 C Language
* 🌐 HTML

각 언어 페이지에서 다음 내용을 확인할 수 있습니다.

* 언어 소개
* 주요 특징
* 사용 분야
* 코드 예제
* 실행 결과
* 퀴즈

---

### 2. 페이지 전환

메인 화면에서 원하는 언어의 버튼을 클릭하면 해당 언어의 설명 화면이 표시됩니다.

각 언어 페이지의 `HOME` 버튼을 클릭하면 다시 메인 화면으로 돌아갈 수 있습니다.

별도의 HTML 파일을 여러 개 만드는 대신 **하나의 HTML 파일에서 JavaScript와 CSS의 `display` 속성을 이용하여 필요한 화면을 표시하는 방식**으로 구현했습니다.

---

### 3. 언어별 퀴즈

각 언어 페이지의 마지막에는 해당 언어와 관련된 퀴즈가 있습니다.

사용자가 선택지를 클릭하면 JavaScript가 선택한 답을 확인하여 결과를 표시합니다.

* ✅ 정답 선택 → 초록색 표시
* ❌ 오답 선택 → 빨간색 표시
* 📖 선택 후 → 문제에 대한 해설 표시

이를 통해 단순히 정보를 읽는 것에서 끝나지 않고 학습한 내용을 직접 확인할 수 있도록 구성했습니다.

## 🔄 동적 기능

이 프로젝트에서는 두 가지 종류의 동적 변화를 구현했습니다.

### 페이지간 동적 변화

메인 화면에서 언어 버튼을 클릭하면 선택한 언어의 설명 화면이 나타납니다.

```text
메인 화면
   ↓
Python 선택
   ↓
Python 설명 화면
   ↓
HOME
   ↓
메인 화면
```

JavaScript의 클릭 이벤트와 `display` 속성을 이용하여 구현했습니다.

### 페이지 내 동적 변화

퀴즈의 선택지를 클릭하면 같은 페이지에서 결과가 변경됩니다.

```text
퀴즈 선택
   ↓
정답 여부 확인
   ↓
정답 / 오답 표시
   ↓
해설 표시
```

사용자의 선택에 따라 선택지의 CSS 클래스가 변경되고 결과 메시지와 해설이 나타납니다.

## 📂 프로젝트 구조

```text
4대-개발언어-가이드/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

### `index.html`

웹사이트의 전체적인 구조와 내용을 담당합니다.

메인 화면과 Python, Java, C, HTML 페이지 및 각 페이지의 퀴즈를 포함하고 있습니다.

### `style.css`

웹페이지의 디자인을 담당합니다.

색상, 크기, 여백, 버튼, 퀴즈 선택지 등의 스타일을 설정했습니다.

### `script.js`

웹페이지의 동적인 기능을 담당합니다.

페이지 전환과 HOME 버튼, 퀴즈의 정답 확인 및 해설 표시 등을 구현했습니다.

## ▶️ 실행 방법

1. 저장소를 다운로드합니다.
2. `index.html` 파일을 실행합니다.
3. 메인 화면에서 원하는 개발 언어를 선택합니다.
4. 각 언어의 설명과 코드 예제를 확인합니다.
5. 퀴즈를 풀어 학습 내용을 확인합니다.

별도의 서버나 프로그램 설치 없이 브라우저에서 실행할 수 있습니다.

## 📚 프로젝트를 통해 배운 점

이번 프로젝트를 통해 HTML, CSS, JavaScript가 각각 어떤 역할을 하는지 실제 웹페이지 제작 과정에서 경험할 수 있었습니다.

특히 JavaScript의 이벤트 처리와 DOM 요소의 표시 상태를 변경하여 하나의 HTML 파일 안에서 여러 화면을 구현할 수 있다는 것을 배웠습니다.

또한 단순한 정보 제공뿐만 아니라 사용자의 입력에 따라 화면의 내용이 달라지는 퀴즈 기능을 구현하면서 **동적인 웹페이지의 기본적인 작동 방식**을 이해할 수 있었습니다.
